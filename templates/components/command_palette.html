{% load i18n %} {% comment %} Command palette, opened with Ctrl/Cmd-K or `/`. The single feature that makes power users describe an application as fast, and a CA carrying three hundred clients is a power user by definition. Search runs server-side against PostgreSQL trigram similarity, debounced at 200ms, and returns a fragment — there is no client-side index to build or keep fresh, and the results are tenant-scoped by the same manager as everything else. The keyboard behaviour advertised in the footer is implemented by the `palette` Alpine component in app.js: ↑/↓ move, Enter opens, Escape closes. {% endcomment %}
