{% load i18n %} {% comment %} A status-coloured donut ring, built from stacked SVG circles. There is no charting library in this app, and every other visual encoding here (status_chip, empty_state) is already inline SVG — this follows the same pattern rather than introducing a new dependency for one chart. `segments` must already carry `pct`, `dasharray` and `offset` — percentages of a circumference normalised to 100 (a circle of r=15.915), computed once by the view (`stacos.tenancy.views._donut_geometry`), since Django's template language cannot keep a clean running sum for the cumulative offset. Each `status` must be one of the status-chip vocabulary keys, so the ring's colours are always the same ones used everywhere else in the product — never invent a one-off colour here. The ring itself is `aria-hidden`: the legend below it repeats every value as real text, the same "colour, icon, word" redundancy `status_chip` uses, so a screen reader or a printed page loses nothing. A segment's `href` is optional, same as `c-stat-card` — when given, its legend row is the link target (`hx-get` into `#main`, same as every other in-app link) rather than a number with no way to see the rows behind it. Size and position are set inline as well as by class, the same belt-and- suspenders `c-icon` uses with its `width`/`height` attributes: an SVG with no intrinsic size renders however large its container happens to be, and a stylesheet that is momentarily stale (a cache, a slow first load) must not turn a small ring into one that fills the card.
