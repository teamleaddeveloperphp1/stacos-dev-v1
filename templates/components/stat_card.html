{% comment %} A single stat tile: icon, number, label. `status` is optional and, when given, must be one of the status-chip vocabulary keys (overdue, due-soon, on-track, complete, ...) — it tints the number with that status's colour via the existing `status-text--{name}` utility class. Leave it blank for a neutral figure (a total, say) that doesn't belong to any one status. `href` is optional. When given, the whole tile is the link target rather than nothing being clickable at all — a count with no way to see the rows behind it is a dead end, not a summary.
