{% load i18n static %} {% comment %} The persistent application shell. This renders ONCE per full page load. Navigation replaces only #main, so the sidebar, header, tenant switcher and notification state never re-render and the application never blinks. That single decision is most of the difference between "a website" and "an app". Every link inside .app-shell inherits hx-boost from the wrapper, so it swaps #main, pushes the URL, and morphs rather than replaces. A direct GET to any of those URLs still returns this full page, which is what keeps deep links, the back button and "open in new tab" working. {% endcomment %} {% block title %}{% translate "STACOS" %}{% endblock %} {% comment %} `hx-ext` is on the body, not on .app-shell. HTMX extensions apply to an element and its descendants, and the command palette, modal container and toast stack all live outside the shell — with the extension scoped to the shell their swaps would silently fall back, and `defaultSwapStyle = "morph"` would name a strategy that was not loaded for them. {% endcomment %} {% translate "Skip to main content" %} {# Progress bar for navigations that outlast ~180ms. #}
