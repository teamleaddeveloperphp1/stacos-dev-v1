{% translate "Why we built it this way" %}

{% blocktranslate %} The obvious product here is a to-do list with due dates. We think that product fails, because the hard question is not “what is due” but “what applies to this business, right now, given what it has become”. A company that opens in a second state or crosses a headcount threshold owes different things, and nothing tells it so. {% endblocktranslate %}

{% blocktranslate %} So applicability is derived from facts about the entity, evaluated against versioned rules, rather than typed once into a template. Coverage grows by publishing rules; it does not wait for a release. {% endblocktranslate %}

{% translate "The second decision" %}

{% blocktranslate %} The business and its professional firm had to be in one system, without either one losing ownership of anything. That made cross-organisation access the most dangerous thing the product does, so it is a first-class, client-approved, time-boxed record with a defined scope — and the client keeps every record when it ends. {% endblocktranslate %}

{% translate "The third" %}

{% blocktranslate %} A compliance record is only worth anything if it can be trusted years later. The audit table is append-only at the database, so nobody — us included — can quietly revise what happened. It is the feature customers notice last and value most. {% endblocktranslate %}
