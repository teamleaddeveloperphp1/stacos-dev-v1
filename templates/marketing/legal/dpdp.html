{% translate "What this notice is" %}

{% blocktranslate %} This is the notice we give you as a data principal under India's Digital Personal Data Protection Act: what personal data we process about you, on what basis, what you can ask of us, and how to complain if we get it wrong. It sits alongside the privacy policy and repeats nothing that policy already covers. {% endblocktranslate %}

{% translate "When we are the fiduciary, and when we are not" %}

{% blocktranslate %} We are the data fiduciary for the personal data of the people who deal with us directly — account users, website visitors and people who contact us. For the personal data our customers hold in their accounts, the customer is the fiduciary and we are a processor acting on their documented instructions. {% endblocktranslate %}

{% blocktranslate %} That distinction decides where a request should go. A request about data inside a customer's account goes to that customer; we will help them answer it and will not act on it independently, because acting would mean disclosing their records to whoever asked. {% endblocktranslate %}

{% translate "The basis on which we process" %}

  • {% translate "Performance of the service you or your organisation asked for — creating your account, authenticating you, billing you." %}
  • {% translate "Compliance with our own legal obligations, including tax record keeping." %}
  • {% translate "Your consent, where we rely on it — for example, marketing email. Consent can be withdrawn at any time, and withdrawing it is as easy as giving it." %}

{% translate "Your rights, and how to use them" %}

  • {% blocktranslate %} Access — a summary of the personal data we hold about you, what we do with it, and who else has received it. {% endblocktranslate %}
  • {% blocktranslate %} Correction and completion — have inaccurate or incomplete data corrected. Most of it you can edit yourself in your account. {% endblocktranslate %}
  • {% blocktranslate %} Erasure — have data deleted where we no longer need it for the purpose it was collected for and no law requires us to keep it. {% endblocktranslate %}
  • {% blocktranslate %} Nomination — nominate someone to exercise these rights on your behalf if you die or become incapacitated. {% endblocktranslate %}
  • {% blocktranslate %} Grievance redressal — complain to us first, and to the Data Protection Board if we do not resolve it. {% endblocktranslate %}

{% blocktranslate with email=company.privacy_email %} Send a request to {{ email }} from the address associated with your account. We acknowledge within two working days and respond substantively within thirty. If we need to verify who you are before acting, we will ask for the least we can get away with — never a copy of an identity document unless nothing else will do. {% endblocktranslate %}

{% translate "Your duties, stated fairly" %}

{% blocktranslate %} The Act asks data principals not to impersonate anyone, not to suppress material information when providing data, and not to file false or frivolous complaints. We mention it because the Act does, not because we expect a problem. {% endblocktranslate %}

{% translate "What we do to make these rights real" %}

  • {% translate "Purpose limitation is enforced by the system: engagements are scoped to named entities and categories, so access follows purpose rather than good intentions." %}
  • {% translate "Retention is a schedule per class of record, applied automatically rather than by anyone remembering." %}
  • {% translate "Consent records — who consented, to what, when, and through which interface — are stored and exportable." %}
  • {% translate "Every access to a record is written to an append-only audit trail, so “who saw this” is answerable." %}
