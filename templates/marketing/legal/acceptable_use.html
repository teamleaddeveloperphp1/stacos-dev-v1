{% translate "The principle" %}

{% blocktranslate %} STACOS holds other organisations' tax records, notices and registers on the same infrastructure as yours. Everything below follows from that: do not use the service in a way that endangers another customer's data, our ability to keep the service running, or anyone's legal position. {% endblocktranslate %}

{% translate "You must not" %}

  • {% translate "Attempt to access data belonging to another customer, or any account you have not been granted access to." %}
  • {% translate "Probe, scan or test the security of the service except under the responsible-disclosure terms on the security page." %}
  • {% translate "Share credentials, or let more people use one account than it was licensed for." %}
  • {% translate "Upload malware, or content you have no right to upload." %}
  • {% translate "Use the service to store data you have no lawful basis to hold." %}
  • {% translate "Impersonate another person or organisation, including when engaging a professional firm or accepting an engagement." %}
  • {% translate "Scrape, resell or redistribute the rule data, the interface or the documentation, or use them to build a competing product." %}
  • {% translate "Send bulk unsolicited messages through any messaging feature we provide." %}
  • {% translate "Place a load on the service, including through the API, that degrades it for others; published rate limits exist for that reason." %}
  • {% translate "Circumvent a limit, quota or billing control, including by creating accounts to extend a trial." %}
  • {% translate "Use the service for anything unlawful under Indian law." %}

{% translate "Automated access" %}

{% blocktranslate %} Use the API rather than driving the web interface with a script: it is documented, versioned, authenticated and rate limited, so we can tell your traffic from an attack. Automation that imitates a browser is indistinguishable from abuse and may be blocked without notice. {% endblocktranslate %}

{% translate "What happens if this is breached" %}

  • {% translate "For most breaches, we contact you, explain what we have seen, and give you a reasonable period to put it right." %}
  • {% translate "Where a breach threatens the security or availability of the service for other customers, we may suspend access immediately and tell you afterwards." %}
  • {% translate "Serious or repeated breaches allow us to terminate the agreement. You still keep your export window unless a law prevents it." %}
