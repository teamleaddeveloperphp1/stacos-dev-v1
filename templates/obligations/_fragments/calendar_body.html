Idiomorph patches matched nodes by calling the real DOM `setAttribute()`, which enforces the XML Name production — and `@` is not a valid Name character. The HTML parser is lenient about it on first paint, so `@change` looks fine until idiomorph re-morphs this element on a later swap and `setAttribute('@change', ...)` throws `InvalidCharacterError`, aborting the swap and leaving `#main` blank. `x-on:` (colon is a valid Name character) is functionally identical to Alpine and survives the morph. {% endcomment %}
